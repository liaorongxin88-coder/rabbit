# Legacy 资料

本目录保存历史业务设计资料和抽取工具。它们是背景参考，不是当前维护入口。

## 文件

- [养兔管理系统完整技术文档.docx](养兔管理系统完整技术文档.docx)：业务设计原件。
- [养兔管理系统完整技术文档.extracted.md](养兔管理系统完整技术文档.extracted.md)：Word 抽取版，便于检索。
- [养兔管理系统完整技术文档.extracted.json](养兔管理系统完整技术文档.extracted.json)：结构化抽取结果。
- [extract_docx.py](extract_docx.py)：历史抽取脚本。

## 使用规则

- 当前实现以源码、Flyway 迁移和 `docs/` 当前索引为准。
- 业务语义不清时，可以用抽取版或 Word 原件核对历史设计意图。
- 如果 legacy 资料和当前代码冲突，先确认当前产品期望，再同步实现和文档。
