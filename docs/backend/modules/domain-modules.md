# 后端业务模块

源码根目录：`backend/src/main/java/com/rabbit/app/modules/`。

## 核心生产

- `house`：兔舍、成员和 `view/edit/control` 权限。
- `cage`：笼位维护、笼位概览和笼位兔只数量。
- `rabbit`：兔只录入、编辑、状态历史、异常、离场和后备。
- `batch`：催情、配种、摸胎、备产、分娩、断奶、出售和繁殖性能。
- `event`：周期事件、提醒扫描、确认闭环和扫描日志。

## 现场记录和经营数据

- `feed`：投喂记录和投喂汇总。
- `treatment`：用药和治疗记录。
- `weight`：称重记录。
- `inventory`：库存项目和库存流水。
- `sale`：销售订单和销售明细。
- `report`：报表和 CSV 导出。

## 平台、审计和基础能力

- `auth`：普通业务用户注册、登录和微信登录兼容。
- `admin`：平台管理员、商户、商户账号和平台侧概览。
- `audit`：接口审计日志。
- `dedup`：写请求幂等去重。
- `nfc`：NFC 标签绑定和目标解析。
- `hardware`：硬件联动网关，默认 noop。
- `setting`：全局设置。

新增后端功能时，先判断它属于现有模块还是需要新模块。不要为了一个接口创建孤立目录。
