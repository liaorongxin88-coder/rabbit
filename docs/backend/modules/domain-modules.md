# 后端业务模块

业务源码分布在 `backend/rabbit-access`、`backend/rabbit-production` 和 `backend/rabbit-reporting`。Rabbit 仍由 `rabbit-boot` 组装成一个 Spring Boot 进程，Maven 模块不是独立服务。

## 身份、兔场和平台

- `auth`：业务账号、密码、短信和运营商一键登录。
- `house`：兔场、成员、邀请、角色和权限。
- `workspace`：把业务账号可访问的兔场投影为工作空间。
- `admin`：平台管理员、业务用户、兔场和平台侧概览。
- `merchant`：保留的兼容模型或迁移边界，不是新的授权层。

账号与兔场之间的授权来源是 `house_users`。新功能不能重新引入商户、组织或其它中间容器来推断兔场权限。

## 生产核心

- `cage`：笼位维护、编号、空间布局和在栏概览。
- `rabbit`：兔只录入、详情、状态历史、异常、离场和后备。
- `batch`：批次查询、批次级操作和繁殖性能。
- `repro`：母兔生产周期、状态机、业务事件和工作任务。
- `event`：提醒查询、确认、扫描和扫描日志。
- `outbound`：批量出库预检、草稿、快照和提交事务。

批次、生产周期、工作任务和出库资格之间存在跨模块契约。修改其中一个模块时，要同步检查 [跨端业务专题](../../features/README.md) 和相关回归测试。

## 现场和经营记录

- `feed`：投喂记录和汇总。
- `treatment`：用药、治疗和复查。
- `weight`：称重记录。
- `inventory`：库存项目和流水。
- `sale`：销售订单和销售明细。
- `report`：报表和导出。

这些数据最终都要归属已授权兔场。有 `house_id` 的表直接过滤，没有 `house_id` 的明细通过父记录完成隔离。

## 基础能力

- `audit`：接口审计。
- `dedup`：写请求的 `requestId` 去重和载荷一致性检查。
- `file`：按兔场隔离的业务图片和附件内容。
- `nfc`：NFC 标签绑定、签名和目标解析。
- `hardware`：硬件网关抽象，默认使用 noop 实现。
- `setting`：账号级和兔场级设置。

新增功能时先选择最接近的业务所有者。跨模块复用只提取稳定契约，不能把业务逻辑堆进没有所有权的通用目录。
