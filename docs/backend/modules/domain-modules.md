# 后端业务模块

源码根目录：`backend/src/main/java/com/rabbit/app/modules/`。

## 核心生产

- `house`：兔场、直接成员关系、精确手机号邀请和 `view/edit/control` 兼容权限。
- `cage`：笼位维护、笼位概览和笼位兔只数量。
- `rabbit`：兔只录入、编辑、状态历史、异常、离场和后备。
- `batch`：催情、配种、摸胎、备产、分娩、断奶、出售和繁殖性能。
- `event`：周期事件、提醒扫描、确认闭环和扫描日志。

## 现场记录和经营数据

- `feed`：投喂记录和投喂汇总。
- `treatment`：用药和治疗记录。
- `weight`：称重记录。
- `inventory`：库存项目和库存流水。
- `sale`：销售订单和销售明细。
- `report`：报表和 CSV 导出。

这些模块都以 `house_id` 为数据边界。控制器和服务不能仅依赖客户端选择，Mapper 查询也必须
直接或通过父表限制在已授权兔场内。

## 账号、平台和基础能力

- `auth`：全局账号、手机号短信登录、账号状态和微信登录兼容。
- `workspace`：把账号直接可访问的兔场投影成多养殖业务工作空间。
- `admin`：平台管理员、业务账号、兔场状态和平台侧概览。
- `audit`：接口审计日志。
- `dedup`：写请求幂等去重。
- `nfc`：NFC 标签绑定和目标解析。
- `hardware`：硬件联动网关，默认 noop。
- `setting`：账号级设置。

新增后端功能时，先判断它属于现有模块还是需要新模块。不要为了一个接口创建孤立目录，
也不要在账号与兔场之间重新引入额外授权层。
