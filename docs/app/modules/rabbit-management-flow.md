# Flutter 兔场管理流程

当前 Flutter 客户端采用多级兔场管理流程：

```text
兔场列表 -> 兔场详情 -> 笼位管理 / 兔只管理 / 生产批次
生产批次 -> 批次详情 -> 批量催情 / 批量配种 / 单兔生产任务 -> 断奶 -> 出库 / 登记离场 -> 批次结束
```

## 路由

- `/houses`
- `/houses/:houseId`
- `/houses/:houseId/cages`
- `/houses/:houseId/rabbits`
- `/houses/:houseId/batches`
- `/houses/:houseId/batches/:batchId`

## 批次详情与现场操作

批次列表以兔舍为边界加载全部批次，支持批次号/备注搜索和状态筛选；点击卡片进入详情，不把批次操作藏在兔舍概览里。详情页按“先汇总、再筛选、后追踪标签”的顺序展示：

- 顶部显示批次状态、日期、活跃追踪标签和结束入口；结束前若仍有活跃标签，必须明确勾选强制结束。
- 统计区区分全部标签、活跃标签、繁殖母兔、商品兔、当前带仔和已退出标签。
- 追踪标签列表支持兔号/笼号/状态/事件搜索、种类筛选、生产状态筛选和在场范围筛选；使用 `ListView.builder`，可承载千级标签。
- 母兔标签的当前阶段、周期数、操作数、窝数、产仔/活仔/断奶数均按 `batchId + motherRabbitId` 聚合，不能读取兔只档案上的全局当前周期来代替；同一母兔同时存在于多个批次时，各标签互不串数据。
- 繁殖标签是否仍有活动由该批次下的开放周期派生；空怀、流产、分笼后历史标签与时间线保留，自动接续的待催情周期不继承旧批次。
- “兔只详情”查看母兔自身档案，“批次记录”只查看该标签在当前批次内的操作时间线；批次接口不向客户端暴露事件 payload 或幂等 `requestId`。
- 有 `control` 权限时，可从当前筛选结果批量开始/完成催情；切换筛选或刷新会清除不可见/已失效选择，网络失败重试复用同一个 `requestId`。
- 有编辑权限时，可从当前筛选结果选择最多 1000 只“待配种”或“哺乳中”的母兔，统一选择配种方式和执行时间后整批提交。体配必须选择种公兔；人工授精仍展示公兔选择但允许不关联具体公兔。完全相同的失败草稿复用稳定 `requestId`，公兔、时间或母兔集合变化后自动换新 ID。
- 活跃繁殖母兔提供“登记离场”入口，可选择淘汰或死亡、填写日期/原因/备注，并在确认不可撤销后调用统一离场事件；服务端会关闭该母兔的开放周期和活跃批次关系。
- 只读权限仍可查看完整标签和生产状态，但不显示写操作；生产表单完成后会刷新批次详情和首页任务队列。
- 生产表单和离场表单完成后会刷新批次详情、兔只/笼位列表和首页任务队列；写请求在同一表单草稿内复用 `requestId`，失败可安全重试。
- 单只催情、配种、摸胎、备产、接产和分笼表单记录日期与时分；“未执行”只推迟提醒，
  不推进阶段。难产与流产必须先拍照或从相册选择图片并填写详情，上传成功后才提交动作。
- 哺乳中的母兔提供“调整留崽数”入口；增加数量时必须选择另一只种母兔作为来源，
  服务端保存原值、新值、来源和操作人，不把来源关系留在备注里。

离场表单已不再限定在批次详情：表单改成全兔种通用后（`batchId` 可空），
笼位详情里的任何一只都能直接登记死亡或淘汰（飞书 recvrpTL16SBwu）；
批次详情仍保留针对活跃繁殖母兔的入口。兔只总表的**批量**离场仍未设计。

## 大型兔舍与权限边界

- 创建批次、兔只列表和批次追踪标签列表均使用分页或惰性构建，不在首帧创建千级复选框/列表项。
- 出库选择页按排/笼使用 Sliver 惰性构建；确认页每次展开 20 个笼位，单笼只展示前 4 个账号和剩余数量，避免 7000 只商品兔形成超长 widget 树或字符串。
- 出库深链在创建任务前校验兔舍权限。只读账号只看到明确的只读状态和返回操作，不会初始化、取消或提交出库任务。
- 统计卡、笼位卡、重置密码弹窗和长标题对 360x800、412x915 与 200% 字号提供稳定尺寸或截断；NFC、出库失败和权限请求均保留明确的重试入口。

## 新增兔只

笼位管理只保留按“层 → 排 → 位”还原现场位置的分层地图；搜索和筛选只压暗不匹配的格子，不再提供扁平列表视图。

新增兔只必须从具体笼位进入：

```text
兔场详情 -> 笼位管理 -> 选择具体笼位 -> 录入兔只
```

不要在兔只列表页新增全局无上下文的“新增兔只”入口。兔只列表页主要用于查看和编辑已有兔只。

## 成熟提醒与生产参数

- 分笼或直接录入商品兔时同步生成出售任务；成熟提醒从首页进入出库流程，出售完成后任务关闭。
- 后备兔成熟提醒执行“转为种兔”，不再重复调用“商品兔转后备兔”。转种保留当前单兔笼；种母兔进入待催情，种公兔进入可配状态。
- 生产设置分为母兔繁育参数和商品兔生长参数。商品兔适应期、生长期、育肥期分别限制为 2–3、15–18、12–15 天，成熟日由三段之和计算。

## 主题和交互

- 正常兔只交互使用主蓝、田野绿和辅助 amber。
- 红色只用于错误或破坏性状态。
- 视觉 token 放在 `app/lib/src/ui/core/theme.dart`。
- 长兔场名、用户名和事件名称必须做省略或换行约束，不能撑破移动端布局。
