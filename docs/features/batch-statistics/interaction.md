# 批次统计交互

- 状态：实施中，交付验收未完成
- 核对日期：2026-09-05
- 适用范围：Admin、Flutter App
- 前置阅读：[交互验收规范](../../project/interaction-acceptance-spec.md)、`admin/DESIGN.md`、`app/.rule`

## 1. 页面落点

完整 28 项统计属于单个批次，不直接铺满数据看板。

| 位置 | 行为 |
| --- | --- |
| Admin `/workspace/production/batches/:batchId` | 独立批次详情，展示全部统计、出肉率操作和 Excel 导出 |
| Admin 生产批次列表 | 活跃和已结束批次都能进入详情 |
| Admin 兔场数据页 | 保留现有四项概览，选中批次后提供完整统计入口 |
| Flutter `/houses/:houseId/batches/:batchId` | 扩展现有详情中的独立统计区 |
| Flutter 数据看板 | 选中批次后提供详情入口 |

统计加载或失败不能阻断批次成员和其他批次操作。

## 2. 分组和排列

统计按配种、怀孕、产崽、选留、断奶、出栏、销售、料肉比八组排列。出肉率位于料肉比组末尾，不增加“屠宰”第九组。

宽屏严格保留飞书原需求的 16 行关系，其中第 14 行是三个销售指标，不得用自动填充网格重新配对：

| 原行 | 分组 | 同行指标 |
| ---: | --- | --- |
| 1 | 配种 | 配种日期 |
| 2 | 配种 | 配种母兔数、受胎率 |
| 3 | 配种 | 配种母兔/公兔比例 |
| 4 | 怀孕 | 怀孕数量、流产率 |
| 5 | 产崽 | 产崽窝数、产崽总数 |
| 6 | 产崽 | 平均窝产数 |
| 7 | 产崽 | 活崽总数、平均活崽率 |
| 8 | 选留 | 选留窝数、选留总数 |
| 9 | 选留 | 选留活崽率、窝均选留 |
| 10 | 断奶 | 断奶数量 |
| 11 | 断奶 | 断奶均重、断奶成活率 |
| 12 | 出栏 | 出栏数量、出栏成活率 |
| 13 | 出栏 | 出栏总重、出栏均重 |
| 14 | 销售 | 总销售金额、销售单价（重量口径）、销售单价（只数口径） |
| 15 | 料肉比 | 全程料肉比、育肥期料肉比 |
| 16 | 料肉比 | 出肉率 |

窄屏或 200% 字号时，把上述各行按指标目录顺序展平成单列，不合并、遗漏或重新配对指标。

组是页面分节，不使用卡片套卡片。指标名称、值、单位和状态应保持稳定尺寸，展开说明不能挤压相邻指标或造成水平滚动。

## 3. 指标状态

| 状态 | 主显示 | 交互 |
| --- | --- | --- |
| `AVAILABLE` | 服务端格式化值和单位 | 可展开公式、分子、分母及组成项 |
| `NOT_APPLICABLE` | 暂无可计算数据 | 说明分母为零 |
| `NOT_RECORDED` | 未录入 | 只有出肉率向具备编辑权限的人员提供录入入口；配种日期没有人工录入入口 |
| `DATA_MISSING` | 历史数据缺失 | 展开“查看口径”后按服务端顺序显示全部原因 |

真实零值必须显示为 0，不能与暂无或缺失混用。`DATA_MISSING` 优先于其他状态；来源不完整时不得显示部分合计。客户端使用服务端 `displayValue`，不自行舍入或计算指标，也不能根据缺失原因的中文文案判断逻辑。

## 4. 加载与刷新

- 首次加载使用统计区骨架，不用全页空白代替。
- 初次失败只替换统计区，提供局部重试。
- 已有成功数据时，刷新失败保留旧数据及原 `calculatedAt`，同时显示失败提示。
- 切换兔舍或批次时丢弃旧请求结果，不能让迟到响应覆盖当前页面。
- 下载和出肉率写入有独立状态，不清空统计结果。

## 5. 出肉率

具备 `rabbit:batches:edit` 时显示录入或修改操作。表单要求：

- 0% < 出肉率 <= 100%。
- 来源单位、检测或屠宰日期和修改说明始终必填；Admin 首次录入时把修改说明预填为“首次录入”。
- 报告编号、凭证和备注可选。
- 保存失败保留输入和同一 `requestId`；输入发生实质变化后使用新的 requestId。

具备 `rabbit:audit:list` 时可以查看完整追加版本。`GET /api/batches/{batchId}/carcass-yields?page=&pageSize=` 返回 `data.items`、`total`、`page` 和 `pageSize`，默认第 1 页、每页 20 条，`pageSize` 最大 200；记录按 `created_at DESC, id DESC` 排列，Admin 通过上一页和下一页浏览。MVP 不提供删除、作废或恢复。

## 6. Excel 导出

只有具备 `rabbit:reports:export` 时才显示导出入口。后端仍需拒绝未授权的直接请求。

Admin 的导出操作位于批次详情页头部，使用带业务 token 和 `X-House-Id` 的 Blob 请求，采用服务端 `Content-Disposition` 文件名，下载结束后释放对象 URL。Flutter 使用带相同认证和兔舍头的受保护文件请求，从 `Content-Disposition` 读取服务端文件名并安全清理，无法解析时使用本地回退名；文件写入临时目录后调起 Android 系统分享或保存，不复用 OTA 下载器，也不申请广泛存储权限。

导出期间禁用重复触发。下载或分享失败显示局部错误，不影响页面统计和其他操作。

## 7. 数据采集交互

- 投喂：一个候选组可自动归属；多批次或多阶段时逐组录入 kg，用量合计必须等于整单总量。保存前分组变化时刷新预览并保留总量输入。
- 断奶：断奶数量大于零时总重必填，界面显示后端派生的平均体重。
- 出库：按批次和未归批次组录入实际重量，使用统一必填重量单价，所有分组重量合计必须等于订单总重量。
- 转后备：服务端按待转换兔只和操作时快照派生来源批次及只数，界面展示只数并要求逐组录入实测总重，不允许用户修改服务端派生只数。

离线出库草稿必须保存新增分配和稳定 requestId，恢复后继续执行相同校验。

## 8. 响应式验收

Admin 验证 `1440x900` 和 `390x844`。Flutter 验证 `360x800`、`412x915` 及 200% 字号。所有场景检查：

- 没有水平溢出、文字遮挡或截断。
- 指标按固定顺序显示，宽屏配对和窄屏单列符合要求。
- 说明、缺失原因和错误信息可以换行。
- 录入、重试、导出和返回操作始终可达。
- 无权限操作不出现，直接请求仍由后端拒绝。
